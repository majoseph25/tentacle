# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through
GitHub's **Security â†’ Report a vulnerability** (private security advisories) on this repository.

Include what you found, how to reproduce it, and the app version. You'll get an acknowledgement
within 7 days. Fixes are released as soon as practical, and reporters are credited unless they ask not to be.

## Scope

In scope: this app's code, its handling of your Jellyfin login and access token, what it exposes to
other apps on the phone, and its network traffic.

Out of scope: the Jellyfin server and the official Jellyfin apps (report those to the
[Jellyfin project](https://github.com/jellyfin/jellyfin/security)), rooted or otherwise compromised
phones, and physical access to an unlocked phone.

## Supported versions

Only the latest release on Google Play / GitHub receives security fixes.

See [docs/SECURITY_ASSESSMENT.md](docs/SECURITY_ASSESSMENT.md) for the most recent security review.
